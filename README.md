# aazzzss-LR_1

## Site preview

Open `index.html` in a browser (double click) or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html`: landing page markup
- `css/style.css`: redesigned theme (colors/typography/layout)
- `images/`: new image set (product, ingredients, reviews, etc.)
